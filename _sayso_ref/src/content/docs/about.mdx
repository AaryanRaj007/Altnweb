## App Language

Change the language of SaySo's user interface. This is separate from the transcription language, which is configured in [Models](/docs/models).

## Version

Shows the current version of SaySo installed on your machine.

## Directories

- **App Data Directory** - Where SaySo stores configuration, models, and recordings
- **Log Directory** - Where SaySo writes log files

You can click these to open them in your file manager. See Debug > Finding Logs for the default paths on each platform.

## Source Code

SaySo is fully open source. You can browse the code, report issues, or contribute on [GitHub](https://github.com/AaryanRaj007/SaySo).

## Acknowledgments

SaySo is a fork of [Handy](https://github.com/cjpais/Handy) by CJ Pais, MIT licensed.

It is built on top of amazing open-source projects, including [Whisper](https://github.com/openai/whisper) and other speech recognition models that make local transcription possible.
